# 다온 (DAON) — 모바일 청첩장 플랫폼

템플릿을 고르고 편집기에서 직접 내용을 채워 모바일 청첩장을 만드는 웹 서비스입니다.
**모든 기능이 무료이며 결제 절차가 없습니다.**

## 화면

| 경로 | 설명 |
| --- | --- |
| `/` | 홈 — 히어로, 템플릿 갤러리, 편집기 소개 |
| `/templates` | 템플릿 12종 전체, 카테고리 필터 |
| `/editor/[templateId]` | 편집기 — 좌측 21개 섹션 / 실시간 폰 미리보기 |
| `/preview/[templateId]` | 완성본 청첩장 전체 화면 |

## 편집기

좌측 아이콘 레일에서 섹션을 고르면 가운데 폼이 바뀌고, 오른쪽 폰 미리보기에 즉시 반영됩니다.

꾸미기 · 디자인 · 배경음악 · 오프닝 · 신랑 정보 · 신부 정보 · 미니앨범 · 예식 정보 ·
초대 글 · 계좌 정보 · 갤러리 · 안내사항 · 하객스냅 · 커플프로필 · 타임라인 · 비디오 ·
방명록 · 선물하기 · 참석여부 · 이미지 · 순서 변경

섹션을 켜면 청첩장에 추가되고 **순서 변경** 목록에 나타납니다. 순서는 드래그로 바꿀 수 있고,
각 패널에서 해당 섹션이 청첩장의 몇 번째에 놓이는지 확인할 수 있습니다.

## 디자인 토큰

색상·타이포·간격은 전부 `app/globals.css` 의 `@theme` 한 곳에서 정의합니다.
아이보리 베이스(`#FDFBF7`)에 더스티 로즈 포인트 1색(`#B08D80`, 텍스트·버튼용 `#8A6558` 은 WCAG AA 통과),
제목은 Noto Serif KR, 본문은 Noto Sans KR 입니다.

- `app/globals.css` — 디자인 토큰과 공통 컴포넌트 클래스
- `app/invitation.css` — 청첩장 렌더러 전용 스타일 (`--iv-*` 테마 변수)
- `app/motion.css` — 바텀 시트, 오프닝 애니메이션, 스크롤 리빌

## 개발

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
npx tsc --noEmit # 타입 검사
npx eslint app components lib
```

## 배포 (GitHub Pages)

`main` 브랜치에 push 하면 `.github/workflows/deploy.yml` 이 정적 사이트를 빌드해 Pages 에 올립니다.
저장소 이름이 곧 basePath 가 되므로(`https://<user>.github.io/<repo>/`) 별도 설정은 필요 없습니다.

저장소 **Settings → Pages → Source** 를 `GitHub Actions` 로 지정해 주세요.

로컬에서 배포본을 그대로 확인하려면:

```powershell
$env:GITHUB_PAGES="true"; $env:NEXT_PUBLIC_BASE_PATH="/wedding-web"; npm run build
npx serve out
```

## 아직 서버가 필요한 기능

정적 사이트라 아래는 화면만 동작하고 데이터가 보관되지 않습니다.

- 참석 의사(RSVP) · 방명록 제출 — 브라우저 안에서만 반영
- 청첩장 발행 및 링크 생성
- 업로드한 사진 — `blob:` URL 이라 새로고침하면 사라짐 (임시저장은 텍스트만 보관)
- 지도 — 네이버·카카오 지도 SDK 와 API 키 필요
- 하객스냅 구글 드라이브 연동

## 모바일 초대장

링크를 받은 사람 앞에 **닫힌 카드**가 놓입니다. 앞장을 누르면 그 장이 왼쪽으로 넘어가며
열리고, 그 아래에서 초대장이 드러납니다 — 열기 전에는 스크롤이 잠깁니다. 초대장은
받아서 «여는» 물건이라, 링크를 누르자마자 글이 좌르륵 나오면 그건 청첩장 웹페이지이지
초대장이 아닙니다.

청첩장(`/templates`, `lib/invitation`)과는 별개의 물건입니다. 청첩장은 길게 내려 읽는
페이지이고, 초대장은 한 장짜리 카드입니다. 코드도 서로 닿지 않습니다.

| 경로 | 설명 |
| --- | --- |
| `/invitation-card` | 디자인 목록 — 행사 6갈래 × 3벌 = 18벌. 접힌 카드가 서 있는 3D 섬네일 |
| `/invitation-card/[design]` | 디자인 한 벌. 실제로 열리는 카드를 그대로 놓습니다 |
| `/invitation-card/make` | 만들고 보내는 화면. `?d=<디자인>` 또는 `?c=<초대장>` 으로 시작 |
| `/invitation-card/v` | **받는 사람이 여는 화면.** `?c=<초대장>` |

### 보내는 방식 — 서버가 없습니다

정적 사이트라 저장할 곳이 없습니다. 그래서 초대장 내용을 서버에 두고 번호를 받아 오는
대신, **내용 자체를 주소 뒤에 실어** 보냅니다.

```
/invitation-card/v/?c=eyJkIjoicG9wcHkiLCJ0Ijoi7Ju...
```

- 가입도 결제도 필요 없고, 적은 글이 브라우저 밖으로 나가는 때는 링크를 직접 보낼 때뿐입니다.
- 링크가 살아 있는 한 초대장도 살아 있습니다. 만료도 삭제도 없습니다.
- 대신 주소가 깁니다. 그래서 열쇠말을 한 글자로 줄이고(`title` → `t`) 빈 칸은 싣지 않습니다.
  **한 번 정한 열쇠말은 바꾸지 마세요** — 이미 보낸 링크가 전부 안 열리게 됩니다.

보내기는 `navigator.share`(카카오톡·메시지), `sms:`, 링크 복사 세 가지입니다.

### 구조

```
lib/occasion/
  types.ts      자료 구조 — Design 이 «디자인 한 벌», InviteData 가 «채워 넣은 내용»
  art.ts        표지 그림 18점의 출처
  designs.ts    디자인 18벌 — 그림 + 그림에서 뽑은 색 + 글꼴 + 표지 판짜기
  occasions.ts  행사 6갈래와 갈래별 예시 내용
  format.ts     날짜·시간·지도·전화·문자 링크
  share.ts      초대장 ↔ 주소 문자열
components/occasion/
  cover.tsx       표지 한 면. 목록의 작은 카드와 화면 가득한 카드가 같은 것을 씁니다
  fold.tsx        목록에 서 있는 접힌 카드 (3D)
  card.tsx        3D 로 열리는 카드 — 덮개·안쪽·여는 연출
  maker.tsx       만들고 보내는 화면
  viewer.tsx      받는 사람 화면
app/occasion.css  전용 스타일. 색은 전부 --oc-* 변수
scripts/fetch-art.mjs  표지 그림을 미술관에서 받아오는 스크립트
```

### 설계 원칙

- **미리보기와 실물이 같습니다** — 목록의 작은 카드도 실제 표지 컴포넌트를 그대로 그립니다.
  글자 크기가 카드 너비(`cqw`)에 매달려 있어서 어느 크기에서든 조판이 같습니다.
- **덮개는 왼쪽으로** — 접힌 자리가 왼쪽이고, 자유단인 오른쪽을 들어 왼쪽으로 넘깁니다.
  반대로 만들면 오른쪽에서 왼쪽으로 읽는 책이 됩니다.
- **색은 그림에서 뽑습니다** — 지어낸 색을 그림 위에 얹으면 아무리 예쁜 색이어도 조잡해집니다.
- **모바일 우선** — 카드는 3:4 비율을 지키면서 화면 높이 안에 들어오도록 «너비»를 줄입니다.
  높이를 잘라 맞추면 비율이 찌그러집니다.
- **누르는 것은 44px 이상**, 본문과 버튼 색은 배경 대비 4.5:1 이상.
- **과하지 않은 움직임** — 여는 연출과 등장(투명도 + 14px 상승)뿐이고,
  `prefers-reduced-motion` 이 켜져 있으면 열린 상태로 시작합니다.
- **의존성 없음** — 3D·등장·공유 모두 브라우저 기본 기능으로 구현했습니다.

### 이미지 라이선스

- `public/samples/` — Pexels 라이선스 (상업적 이용·수정 가능, 출처 표기 불필요)
- `public/art/` — **시카고 미술관 오픈액세스 CC0(퍼블릭 도메인)** 18점.
  `is_public_domain` 이 참인 소장품만 씁니다. 법으로 요구되지는 않지만 작가와 소장처는
  카드 맨 아래와 디자인 페이지에 밝힙니다. 출처는 `public/art/credits.json`.
