Cardly — 인쇄물 PDF 에 심는 글꼴
================================

여기 있는 글꼴 여섯 벌은 모두 SIL 오픈 폰트 라이선스(OFL) 1.1 로 배포됩니다.
라이선스 전문은 같은 폴더의 OFL.txt 에 있습니다.

  NanumGothic-Regular.ttf / NanumGothic-Bold.ttf
      Nanum Gothic — Copyright (c) NHN Corporation

  GothicA1-Regular.ttf / GothicA1-Bold.ttf
      Gothic A1 — Copyright (c) Hanken Design Co.

  NanumMyeongjo-Regular.ttf / NanumMyeongjo-Bold.ttf
      Nanum Myeongjo — Copyright (c) NHN Corporation

  DoHyeon-Regular.ttf
      Do Hyeon — Copyright (c) Woowa Brothers

  BlackHanSans-Regular.ttf
      Black Han Sans — Copyright (c) Zess Type

  Jua-Regular.ttf
      Jua — Copyright (c) Woowa Brothers

모두 github.com/google/fonts 의 ofl/ 아래에서 받았습니다.

OFL 이 요구하는 것은 둘입니다. 글꼴 파일 자체를 팔지 말 것, 그리고 파일을
재배포할 때 라이선스 사본을 함께 둘 것. 글꼴로 만든 결과물(인쇄물·PDF·이미지)
에는 제약이 없고, 결과물을 파는 것도 허용됩니다. PDF 안에 글꼴을 심는 것
(embedding)도 OFL 이 명시적으로 허용합니다.

자세한 사정은 docs/print-fonts.md 에 있습니다.
